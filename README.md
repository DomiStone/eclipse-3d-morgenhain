# ECLIPSE 3D – Morgenhain ⚔️

Ein kostenloses Fantasy-Browser-RPG mit Dorf, NPCs, Monstern, Quests und einem Schattenwächter.

## Spielen
Öffne `index.html` in einem modernen Browser. Das Spiel benötigt keinen Build-Prozess, keine Installation und keine externen Bibliotheken.

## Steuerung
- **Joystick links** / **WASD**: Laufen
- **Finger über das Spielbild ziehen**: Kamera drehen
- **⚔️** / **Leertaste**: Schwertangriff
- **✨** / **R**: Magie
- **🧪** / **H**: Heiltrank
- **💬** / **F**: Mit NPCs sprechen, handeln, Truhen öffnen
- **↻**: Spielstand löschen und neu beginnen

## Abenteuer
Sprich zuerst mit Mira nördlich des Brunnens. Besiege drei Schattenwölfe, kehre zurück und stelle dich anschließend dem Schattenwächter. Borin verbessert dein Schwert für 25 Gold; Lysa verkauft Heiltränke für 12 Gold. Der Brunnen heilt kostenlos. Truhen in der Wildnis enthalten Beute.

Der Spielstand wird im Browser mittels `localStorage` automatisch gespeichert.

## GitHub Pages
In den Repository-Einstellungen unter **Settings → Pages → Build and deployment** als Source **Deploy from a branch**, Branch **main**, Ordner **/(root)** wählen und speichern. Danach ist das Spiel über die GitHub-Pages-Adresse erreichbar.

## Technik
Reines HTML, CSS und JavaScript mit Canvas 2D und perspektivischer Pseudo-3D-Darstellung. Keine Drittanbieter-Abhängigkeiten.
